# KTEO News System

Digital signage news platform for **Autovision KTEO**, delivering daily news
across 53 inspection-centre screens.

The system aggregates RSS news, classifies items with Claude (Anthropic), and
publishes per-category XML feeds that drive a self-hosted browser widget
displayed via Yodeck.

See `LICENSE` for usage terms.
